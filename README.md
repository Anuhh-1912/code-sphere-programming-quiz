# SkillSprint Pro 🎓

**Programming Quiz & Assessment Platform**

SkillSprint Pro is a responsive, single-page web application designed to help learners practise programming, take quizzes, review performance, and track learning progress.

## ✨ Features

- User registration and login interface
- Personalised onboarding and learning preferences
- Programming topics and quiz questions
- Quiz scoring and result review
- Progress analytics and quiz history
- Saved questions for revision
- Leaderboard
- Badges and certificates section
- Mock exams and study notes sections
- Settings and theme options
- Responsive layout for desktop and mobile screens
- Browser `localStorage` for demo data persistence

> **Note:** This is a front-end demo. Login and account information are not backed by a secure server or production authentication system. Do not use real passwords or sensitive personal information. Data stored in `localStorage` stays in that browser on that device.

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Browser `localStorage`

## 🚀 Run Locally

No build tools or package installation are required.

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the **Live Server** extension in VS Code.
4. Start exploring the app.

## 🔒 Data and Privacy

This project is designed as a client-side demonstration. User data is stored locally in the browser where applicable. Clearing browser site data may remove it. There is no server-side database or secure authentication configured in this single-file version.
